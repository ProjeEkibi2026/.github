## 🤝 Katkıda Bulunun

Projelerimize katkıda bulunmak ister misiniz? Harika! İşte nasıl başlayabileceğiniz:

1. 🍴 Projeyi fork'layın
2. 🌿 Yeni bir branch oluşturun (`git checkout -b feature/YeniOzellik`)
3. ✨ Değişikliklerinizi commit'leyin (`git commit -m 'Yeni özellik eklendi'`)
4. 📤 Branch'inizi push'layın (`git push origin feature/YeniOzellik`)
5. 🎉 Pull Request açın

### 📋 Katkı Kuralları
- Kodunuzun temiz ve okunabilir olduğundan emin olun
- Değişikliklerinizi açıklayıcı commit mesajlarıyla kaydedin
- Mümkünse testler ekleyin
- Dokümantasyonu güncel tutun
